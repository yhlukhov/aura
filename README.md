# AURA ✦ Простір онлайн-медитацій та духовних практик

Сучасна платформа для анонсування, пошуку та промоції живих онлайн-подій у сфері медитацій, Рейкі, звукотерапії та енергопрактик.

---

## 🌿 Особливості проєкту

* **Атмосферний медитативний дизайн**:
  * Палітра спокою: теплий льон, шавлія, аметист, золото та затишний пісок.
  * Витончена типографіка: *Cormorant Garamond* (заголовки) та *Plus Jakarta Sans* (текст).
  * Ефект **Ambient Glow**: динамічна фонова підсвітка банера майстра в тонах самого зображення без спотворення пропорцій.
  * Напівпрозорі скляні панелі (*Glassmorphism*).

* **Головна сторінка**:
  * Пошук практик та провідників за ключовими словами та тегами.
  * Інтерактивна фільтрація за категоріями:
    * 🌿 Рейкі (Reiki)
    * 🧘 Медитації (Mindfulness)
    * 🔮 Енергопрактики
    * 🔔 Звукотерапія (Sound Healing)
    * 🌬 Дихальні практики (Pranayama)
    * 🌸 Жіночі кола
  * Фільтрація за форматом участі: *Вільний донейшн*, *Безкоштовно*, *Фіксований внесок*.
  * Промо-блок «⭐ Топ події тижня» для підвищеної видимості практик.

* **Сторінка події (`/events/[id]`)**:
  * Великий банер з ореолом аури.
  * Детальна програма та таймінг сесії.
  * Блок «Що підготувати до зустрічі» (свічка, навушники, плед, вода).
  * Картка провідника/майстра з біографією та контактом у Telegram.
  * Модальне вікно швидкого запису з посиланням на Zoom/Meet та інтеграцією з **Google Calendar**.

* **Кабінет організатора (`/create`)**:
  * Форма створення події з вибором категорії, дати за київським часом та посилань.
  * Галерея естетичних банерів-пресетів або завантаження власного URL.
  * **Live-прев'ю**: майстер бачить у реальному часі вигляд картки в каталозі та банера з аурою на сторінці.
  * Промо-опції просування.

## 🛠 Технологічний стек

* **Фреймворк**: [Next.js 14](https://nextjs.org/) (App Router, React 18, TypeScript)
* **Стилізація**: [Tailwind CSS](https://tailwindcss.com/)
* **Іконки**: [Lucide Icons](https://lucide.dev/)
* **Шрифти**: Google Fonts (*Cormorant Garamond*, *Plus Jakarta Sans*)

## 🚀 Локальний запуск

1. Клонувати репозиторій:
   ```bash
   git clone https://github.com/yhlukhov/aura.git
   cd aura
   ```

2. Встановити залежності:
   ```bash
   npm install
   ```

3. Запустити сервер розробки:
   ```bash
   npm run dev
   ```

4. Відкрити у браузері: [http://localhost:3000](http://localhost:3000)
